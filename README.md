# 🍽️ FastGoodCuisine

## 🧾 Description

**FastGoodCuisine** is a web application designed to bring together many cooking enthusiasts around one common passion — cuisine.  
This forum allows users to discuss and share various recipes from different cultures and backgrounds.

---

## ✨ Features

- 🧑‍🍳 Register an account
- 🔐 Log in
- 📤 Share your own recipes
- 📖 Browse and view delicious recipes
- 🍲 Cook tasty dishes with ready-to-use recipes

---

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** Go (Golang)

---

## 🚀 Installation

### Prerequisites

- Go 1.24 or higher
- Git

### Clone the repository

    git clone https://github.com/MaynadieLilian/fastgoodcuisine

### Run the project

    cd cmd
    go run main.go

---

## 💻 Usage

Once the application is running, open your browser and go to:

👉 [http://localhost:8080](http://localhost:8080)

- 🔑 **Login:** Use your credentials
- 📝 **Register:** Create a new account if you don’t have one
